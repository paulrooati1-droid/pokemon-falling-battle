# Pokémon Falling Battle

Primer avance de Proyecto 1 — Laboratorio 3, CMP1001.

Aplicación interactiva de dos jugadores hecha con HTML, CSS y JavaScript.
- Jugador 1 controla piezas tipo Tetris.
- Jugador 2 controla un Pokémon y debe sobrevivir.
- Las piezas son aleatorias.
- Cada fila completada entrega una bomba.
- La bomba inflige 25 HP.
- El daño de una pieza es de 15 HP.
- Snorlax: la habilidad **Resistencia** ahora realiza un salto potente.
- Se agregó **Pausa / Continuar** con la tecla **P** y un botón visible.

## Controles
- Jugador 1: ← → ↓ ↑, ESPACIO y B.
- Jugador 2: A, D, W, S y P.

## Alcance
Versión de trabajo para el checkpoint de Laboratorio 3. No requiere backend, base de datos, autenticación, APIs externas ni frameworks.
